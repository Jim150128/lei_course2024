# Nginx Web服务器搭建实验情况说明

## 一、实验目的

本次实验主要学习在 Ubuntu 系统中安装和配置 Nginx Web 服务器，掌握 Nginx 的基本安装方法、虚拟机 IP 地址查询方法，以及 Web 根目录下网页文件的修改方法，并能够通过 Windows 浏览器访问虚拟机中的 Web 页面。

## 二、实验环境

- 虚拟机软件：VMware Workstation
- 操作系统：Ubuntu
- Web服务器：Nginx
- 浏览器：Windows 浏览器

## 三、实验过程

### 1. 安装 Nginx

在 Ubuntu 终端中输入：

```bash
sudo apt install nginx -y
````

完成 Nginx Web 服务器的安装。

### 2. 查询虚拟机 IP 地址

输入：

```bash
ifconfig
```

查看 Ubuntu 虚拟机当前使用的 IP 地址。

随后回到 Windows 系统，在浏览器地址栏中输入虚拟机的 IP 地址。

浏览器能够正常显示 Nginx 的默认欢迎页面，说明 Nginx 已经成功安装并能够正常运行。

### 3. 修改网页内容

为了修改 Nginx 默认显示的网页，进入 Web 根目录：

```bash
cd /var/www/html
```

对 `index.html` 文件进行编辑。

老师要求网页显示的基本内容为：

```html
<html>
<body>
hello, njupt
</body>
</html>
```

在完成老师要求的基础上，我对网页内容进行了简单修改，在页面中增加了自己的学号和姓名，使页面能够显示个人实验信息。

例如：

```html
<html>
<body>
<h1>hello, njupt</h1>
<p>学号：XXXXXXXX</p>
<p>姓名：XXX</p>
</body>
</html>
```

保存文件后，在 Windows 浏览器中重新访问虚拟机 IP 地址，可以看到修改后的网页内容。

## 四、实验过程中遇到的问题

在第一次向网页中加入自己的姓名时，浏览器中出现了中文乱码的问题，中文内容无法正常显示。

发现问题后，我立即进行了检查，并将网页字符编码统一设置为 UTF-8，对网页代码进行了修改。

修改后的网页结构如下：

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>Nginx实验</title>
</head>
<body>
    <h1>hello, njupt</h1>
    <p>学号：XXXXXXXX</p>
    <p>姓名：XXX</p>
</body>
</html>
```

保存并重新刷新浏览器后，中文乱码问题得到解决，学号和姓名均能够正常显示。

## 五、实验结果

本次实验完成了以下内容：

* [x] 成功安装 Nginx
* [x] 成功启动 Web 服务
* [x] 成功查询虚拟机 IP 地址
* [x] 成功通过 Windows 浏览器访问 Nginx 页面
* [x] 成功修改 `/var/www/html/index.html`
* [x] 在老师要求的基础上增加了自己的学号和姓名
* [x] 发现并解决了中文乱码问题
* [x] 最终网页能够正常显示个人信息

通过本次实验，我了解了 Nginx Web 服务器的基本安装和使用方法，学会了通过虚拟机 IP 地址在 Windows 浏览器中访问 Ubuntu 中的 Web 服务，同时掌握了修改 Nginx 默认网页的方法。
